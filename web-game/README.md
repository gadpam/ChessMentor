# Системный администратор — браузерный симулятор офиса

Игра в духе «Симулятора системного администратора»: вы единственный сисадмин офиса.
Сотрудники звонят с жалобами, вы идёте к устройству, диагностируете и чините его,
зарабатываете деньги, покупаете запчасти и переживаете рабочие смены.

Чистый HTML/JS/Canvas, без сборки и зависимостей.

## Запуск

```bash
cd web-game
python3 -m http.server 8080        # или: npm start
```

Открыть http://localhost:8080. Файлы можно открыть и напрямую, но модули ES
надёжнее работают через HTTP-сервер.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` / стрелки | ходить |
| `E` / `Enter` / `Space` | осмотреть ближайшее устройство или открыть склад |
| `Esc` | закрыть окно |

Заявку в правой панели можно отметить кнопкой «Показать на карте» — устройство подсветится.

## Как играть

- **Заявки.** Жёлтый «!» над устройством означает открытую заявку. У каждой есть таймер.
- **Диагностика.** Подойдите к устройству и нажмите E. Перед вами список действий,
  только один-два из них реально чинят поломку. Каждая попытка тратит секунды.
- **Ошибки.** Неверное действие снимает 1 очко репутации и тратит время.
  Просроченная заявка снимает 6 очков. Устройство при этом остаётся сломанным.
- **Склад (H, правая нижняя комната).** Запчасти (блок питания, картридж, жёсткий диск)
  расходуются при ремонте. Лицензия антивируса и кроссовки покупаются один раз.
- **Конец смены.** Списываются расходы, незакрытые заявки переносятся на следующий день
  с −2 репутации за каждую. Репутация 0 — увольнение. Долг ниже −300 ₽ — банкротство.

Прогресс сохраняется в `localStorage` каждые 2 секунды во время смены.

## Структура

```
web-game/
  index.html        разметка и HUD
  css/style.css     оформление
  js/data.js        баланс: карта, неисправности, действия, склад, расходы
  js/game.js        игровая логика без DOM (тестируется)
  js/render.js      отрисовка мира на Canvas
  js/ui.js          список заявок, журнал, модальные окна
  js/main.js        цикл кадров, ввод, автосохранение
  tests/            тесты игровой логики (node:test)
```

Логика отделена от отрисовки, поэтому баланс и новые неисправности правятся в `data.js`,
а поведение проверяется тестами без браузера.
