# ChessMentor для Android

Импортируйте сыгранную партию, разберите её на доске со Stockfish и попробуйте исправить свои ошибки, не открывая лучший ход заранее. Партии и тренировочный прогресс хранятся на устройстве. ChessMentor — независимое приложение, не связанное с Chess.com. Ник для публичного архива Chess.com и профиль внутри ChessMentor — разные вещи.

## Как начать, если у вас только GitHub и телефон

1. Откройте [Actions → Android CI](https://github.com/gadpam/ChessMentor/actions/workflows/android-ci.yml). Выберите успешный запуск **нужной ветки и коммита**: `master` для уже объединённых изменений или ветку PR для проверки до слияния.
2. Внизу страницы запуска в **Artifacts** скачайте `chessmentor-apks` (для загрузки войдите в GitHub). Распакуйте архив и установите **`app-debug.apk`** на Android 10 или новее, на устройстве с поддерживаемой 64-битной архитектурой. `app-release-unsigned.apk` не предназначен для установки. Артефакты CI хранятся 14 дней; если архив истёк, нужен новый запуск. [Подписанные релизы](https://github.com/gadpam/ChessMentor/releases) — отдельный канал, не результат каждого слияния PR.
3. При первом старте чистой debug-сборки доступен локальный тестовый профиль. Если видите форму входа, выберите «Войти как тестировщик» или войдите в свой профиль. Уже сохранённая сессия имеет приоритет. В release нет тестового входа.
4. Для быстрой проверки нажмите мини-доску **«Задача дня»**. Для своей партии откройте **«Недавние партии» → «Добавить» → «С Chess.com»**, введите публичный ник, отметьте партии и подтвердите импорт. Пароль Chess.com не нужен. Альтернатива — вставить текст PGN или выбрать файл `.pgn`.
5. В **«Партиях»** нажмите **«Разобрать партию»**. В сводке выберите ход под графиком; на доске стрелки перелистывают полуходы, а **«К моменту»** пропускает промежуточные ходы. Первичная загрузка сети NNUE для движка требует интернета; скачивание архива Chess.com — отдельная операция.

**Перед переустановкой:** если Android не принимает обновление из-за другой подписи, не удаляйте приложение, пока не сохраните прогресс. В настройках откройте **«Данные и резервная копия» → «Полная резервная копия (.json)»** и сохраните файл вне данных приложения. Экспорт `.pgn` переносит партии, но не заменяет копию тренировочного прогресса. После установки войдите в нужный локальный профиль и выберите «Восстановить из копии (.json)».
