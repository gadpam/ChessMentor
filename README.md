# ChessMentor для Android

Импортируйте сыгранную партию, разберите её на доске со Stockfish и попробуйте исправить свои ошибки, не открывая лучший ход заранее. Партии, оценки и тренировочный прогресс хранятся локально в базе Room (версия схемы 5, 6 таблиц) и `SharedPreferences` без собственного сервера и скрытого сбора данных. ChessMentor — независимое приложение, не связанное с Chess.com. Ник для публичного архива Chess.com и профиль внутри ChessMentor — разные вещи.

Внутри собраны нативный движок Stockfish 19 (NDK C++17 для `arm64-v8a` и `x86_64`, внешняя нейросеть NNUE `nn-1a298aa575a0.nnue` с проверкой SHA-256), локальная дебютная книга (28 позиций/линий), калиброванная Win%-модель оценки ходов, 46 встроенных тактических задач + автоматическая генерация задач из ваших ошибок, интервальное повторение Лейтнера + SM-2 и статистика по 37 тактическим паттернам. Требуется Android 10 (API 29) или новее.

## Как начать, если у вас только GitHub и телефон

1. Откройте [Actions → Android CI](https://github.com/gadpam/ChessMentor/actions/workflows/android-ci.yml). Выберите успешный запуск **нужной ветки и коммита**: `master` для уже объединённых изменений или ветку PR/рабочую ветку для проверки до слияния.
2. Внизу страницы запуска в **Artifacts** скачайте `chessmentor-apks` (для загрузки войдите в GitHub). Распакуйте архив и установите **`app-debug.apk`** на Android 10 или новее, на устройстве с поддерживаемой 64-битной архитектурой (`arm64-v8a` или `x86_64`). `app-release-unsigned.apk` не предназначен для установки. Артефакты CI хранятся 14 дней; если архив истёк, нужен новый запуск. [Подписанные релизы](https://github.com/gadpam/ChessMentor/releases) — отдельный канал, не результат каждого слияния PR.
3. При первом старте чистой debug-сборки доступен локальный тестовый профиль (`TesterProfiles`). Если видите форму входа, выберите «Войти как тестировщик» или зарегистрируйте свой локальный профиль. Уже сохранённая сессия имеет приоритет. В настройках `debug`-сборки также есть кнопка **«Добавить демо-партии и задачи (Debug)»**, чтобы сразу проверить графики, разбор и тренировки на готовых данных без ожидания NNUE. В `release`-сборке тестового входа и фикстур нет.
4. Для быстрой проверки нажмите мини-доску **«Задача дня»**. Для своей партии откройте **«Недавние партии» → «Добавить» → «С Chess.com»**, введите публичный ник, отметьте партии и подтвердите импорт. Пароль Chess.com не нужен. Альтернатива — вставить текст PGN или выбрать файл `.pgn`.
5. В **«Партиях»** нажмите **«Разобрать партию»**. В сводке выберите ход на графике или через текстовый список; на доске стрелки перелистывают полуходы, а **«К моменту»** переходит к следующему ключевому моменту. Первичная загрузка сети NNUE (`nn-1a298aa575a0.nnue`, ~67 МБ, с проверкой SHA-256 и требованием ~96 МБ свободного места) требует интернета; скачивание архива Chess.com — отдельная операция. После скачивания NNUE весь разбор и тренировки работают полностью офлайн.

**Перед переустановкой:** если Android не принимает обновление из-за другой подписи, не удаляйте приложение, пока не сохраните прогресс. В настройках откройте **«Данные и резервная копия» → «Полная резервная копия (.json)»** и сохраните файл вне данных приложения (облачный автобэкап Android намеренно исключает БД Room, `user_session.xml` и каталог `nnue`). Экспорт `.pgn` переносит партии, но не заменяет копию тренировочного прогресса. После установки войдите в нужный локальный профиль и выберите «Восстановить из копии (.json)».
