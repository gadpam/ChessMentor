# Импорт публичных партий Chess.com в ChessMentor

[К документации проекта](../README.md)

**Вывод на 19.11.2026:** для загрузки завершённых партий достаточно официального Published-Data API и публичного ника. В приложении используется ручная загрузка с выбором партий до сохранения. Это источник данных, а не вход в аккаунт и не подтверждение, что ник принадлежит пользователю. **Реализовано в Android:** «Недавние партии» → «Добавить» → «С Chess.com» → ник → месяц → отметить партии → «Импортировать выбранные». Сохранённые игры доступны в разделе «Партии». При повторном открытии используется ник текущего локального профиля. Проверка с живым сервисом на телефоне ещё нужна; автоматические тесты используют фиктивные архивы.

## Альтернатива без встроенного подключения

В браузере открыть `https://api.chess.com/pub/player/{ник}/games/{год}/{месяц}/pgn` (месяц двумя цифрами), скачать PGN, затем в ChessMentor выбрать **«Недавние партии» → «Добавить» → «Файл .pgn»** и проверить предпросмотр. [Официальный пример для февраля 2025](https://api.chess.com/pub/player/hikaru/games/2025/02/pgn) приведён в [инструкции Chess.com](https://support.chess.com/en/articles/8705305-how-do-i-get-a-pgn-of-my-game). В большом месяце это не импорт без ограничений: действующий пакетный импорт рассматривает первые 50 партий и ограничивает размер текста.

## Как работает кнопка «С Chess.com»

| Шаг | Действие игрока | Что делает приложение |
|---|---|---|
| 1. Источник | Ввести ник и нажать «Загрузить архив» | Приложение читает публичные партии без пароля. Подтверждённый ник запоминается для текущего локального профиля. Его можно сменить или забыть без удаления партий. |
| 2. Период | Оставить последний доступный месяц или выбрать «Раньше» / «Позже» | Список месяцев берётся из `GET /pub/player/{ник}/games/archives`. Пустому архиву соответствует сообщение «В публичном архиве пока нет партий». |
| 3. Выбор | Отметить одну или несколько новых партий | Из `GET /pub/player/{ник}/games/{YYYY}/{MM}` приложение показывает до десяти недавних встреч с датой, соперником, стороной и результатом. Строка «Уже в библиотеке» не выбирается; «Открыть партию №…» ведёт в локальную сводку. |
| 4. Сохранение | Сверить число и нажать «Импортировать выбранные (N)» | Только теперь выбранные записи попадают в библиотеку. Цвет определяется по нику источника. Анализ не стартует; его можно запустить позже из «Партий». |

Для такого экрана месячный **JSON** удобнее цельного файла PGN: можно показать конкретные партии до разбора архива. Это разные представления одного источника, не два обязательных скачивания. Форматы и поля: [официальный справочник endpoint’ов](https://www.chess.com/news/view/published-data-api).

## Устройство и ограничения

- **Чтение:** [ChessComArchive и ChessComHttp](../app/src/main/java/com/example/chessmentor/data/chesscom/ChessComArchive.kt) строят URL на `https://api.chess.com`, ограничивают символы ника и проверяют год/месяц. У OkHttp тайм-аут вызова 25 секунд, предел ответа 4 МиБ, дисковый HTTP-кеш 12 МиБ. Перенаправления и автоматические повторы отключены. Для слишком большого ответа предлагаются другой месяц или PGN-файл.
- **Выбор:** сначала сортировка по `end_time` (новые первыми), затем проверка PGN, результата и стороны ника, устранение повторов по отпечатку и ограничение десятью строками. Только `rules = chess`; текущие партии, нечитаемые PGN и варианты вроде Chess960 не попадают в список. Это не постраничная выдача всей истории месяца. При смене месяца или ника выбор сбрасывается; старый вызов отменяется. Окно не сохраняет флажки при закрытии.
- **Хранение:** [GameViewModel](../app/src/main/java/com/example/chessmentor/presentation/viewmodel/GameViewModel.kt) сопоставляет отпечатки с играми текущего профиля. Если в библиотеке несколько копий, кнопка открытия ведёт к меньшему из сохранившихся ID. Выбранные новые записи группируются по цвету и сохраняются через `UploadGameUseCase.executeBatch`, без подстановки локального ника и без запуска движка. «Забыть ник» убирает настройку источника, не удаляет игры и не очищает HTTP-кеш.
- **Сеть:** отмена до подтверждения не меняет библиотеку. Для `404` проверьте ник или месяц, для `410` архив больше недоступен. При `429` клиент делает паузу на `Retry-After` в секундах (от 1 секунды до суток; по умолчанию 60 секунд). Кешированием и условными GET управляет OkHttp по заголовкам сервера; не стоит ожидать мгновенного появления только что завершённой игры. [Правила и коды ответов Chess.com](https://support.chess.com/en/articles/9650547-published-data-api).
- **Независимое приложение:** это чтение публичного архива, не OAuth, не фоновая синхронизация и не доступ к приватным данным. Сервер ChessMentor, ключ API и пароль Chess.com для этого сценария не используются. [Условия PubAPI](https://support.chess.com/en/articles/9650547-published-data-api).

## Что проверено, а что проверить вручную

[ChessComImportTest](../app/src/androidTest/java/com/example/chessmentor/presentation/ui/ChessComImportTest.kt) подставляет JSON с 61 записью, проверяет выбор десяти свежих стандартных партий, сторону игрока, локальный дубликат и его ID. UI-сценарий проверяет смену месяца и явное подтверждение выбора. Это не тест реальной сети, HTTP-кеша или лимитов Chess.com.

На телефоне проверить публичный ник из своей сети, месяц без подходящих записей, отсутствие сети и повторный импорт той же партии. На контролируемом тестовом сервере ещё полезно проверить `304`, `429`, слишком большой и оборванный ответ. Подробный [маршрут приёмки и шаблон отчёта](testing.md).
