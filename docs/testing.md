# Проверка ChessMentor через GitHub

[Быстрый старт и установка](../README.md) · [Карта интерфейса](android-ui-inventory.md) · [Что проверять после изменений уровня 1](integrity-and-analysis-fixes.md)

## Как выбрать сборку и прочитать проверки

В [Android CI](https://github.com/gadpam/ChessMentor/actions/workflows/android-ci.yml) проверьте **ветку и SHA**. Для полного прогона с правом запуска: **Run workflow → нужная ветка → Run workflow**. Обычный push/PR и ручной запуск отличаются:

| Задание / артефакт | Что подтверждает | Чего не подтверждает |
|---|---|---|
| Unit Tests, Room Schema & Android Lint → `test-lint-and-room-schema` | JVM-тесты, экспорт схемы и статический анализ | Правильное расположение кнопок на вашем телефоне |
| Build Debug & R8 Release APKs → `chessmentor-apks` | Обе сборки, R8 mapping и выравнивание ELF нативной библиотеки для поддерживаемых ABI | Что релиз подписан постоянным ключом или опубликован |
| Backup restore on Android (Room) → `android-device-test-results` | Несмотря на название, запускает **весь** `connectedDebugAndroidTest`: Room, движок, Compose и навигацию на API 29 x86_64 | В обычном push/PR задание пропускается. Проверка с тестовым JSON архива — не запрос к Chess.com из сети пользователя. |
| Verify release signing with a disposable key | Работоспособность процедуры подписи на временном ключе | Наличие постоянных секретов или возможность обновить уже установленный release |

Например, [полный прогон для `6639dd3`](https://github.com/gadpam/ChessMentor/actions/runs/44712950293) относится к изменению обработки дубликатов в [PR #15](https://github.com/gadpam/ChessMentor/pull/15). Артефакт может истечь раньше, чем ссылка на страницу прогона. Актуальный результат для другого коммита смотрите в его Checks.

## Короткий маршрут на телефоне

Это сценарии проверки, а не утверждение, что каждый телефон уже проверен. Для удаления и восстановления берите тестовый профиль и партии, которые можно потерять.

| Где | Что сделать | Наблюдаемый результат |
|---|---|---|
| Главная | Нажать мини-доску задачи дня, вернуться, нажать «Начать тренировку» | Сначала открывается ежедневная задача, затем отдельная сессия из десяти. |
| PGN | Вставить одну партию, до импорта заменить её другой с иными именами и цветом | Старые имена и автоцвет исчезают; пока новый текст проверяется, импорта нет. Для архива с повтором число новых записей меньше общего числа блоков. |
| Chess.com, живая сеть | Загрузить свой публичный архив, отметить одну новую партию, подтвердить, снова открыть тот же месяц | Сторона и соперник соответствуют партии. Теперь запись недоступна для повторного выбора; «Открыть партию №…» ведёт в локальную сводку. При ошибке сети библиотека не должна измениться. |
| Дубликат из файла | Открыть тот же PGN. Нажать «Создать отдельную копию» → «Отмена», затем «Открыть партию №…» | После отмены копии нет. Открывается существующая запись; «Назад» из сводки возвращает к импорту. Только «Создать и разобрать» разрешает отдельную копию. |
| Библиотека | Совместить имя соперника с неподходящим фильтром; нажать «Показать все партии». Вызвать корзину у одной из двух встреч и отменить. | Выдача отличает отсутствие совпадений от пустой базы; сброс не меняет сортировку. Номер в диалоге соответствует карточке, отмена оставляет записи на месте. |
| Анализ и доска | Запустить разбор, отменить. После успешного разбора выбрать полуход из списка под графиком; сравнить стрелку вперёд и «К моменту». | После отмены нет автоперехода. В сводке ход открывает нужную позицию; стрелка — один полуход, отдельная кнопка — ключевой момент. |
| Тренировки и статистика | Из ошибки своей партии открыть тренажёр; из статистики выбрать другой период | Упражнение относится к выбранной партии, а не к случайному сопернику. Период без партий не трактуется как нулевая точность. |
| Настройки / доступность | Выбрать тему доски, вернуться к задаче. Увеличить шрифт, включить TalkBack и открыть настройки из шапки. | Доска использует выбранную тему. Полное имя и рейтинг доступны для чтения, шестерёнка остаётся отдельным действием. Фактическую речь и жесты проверять на устройстве. |
| Резервная копия | Сохранить JSON через системный выбор файла. Восстановить в тестовый профиль, повторить импорт. | Сверить количество партий и попыток, открыть восстановленный разбор. Не ожидать восстановления пароля или привязки ника источника Chess.com. |

## Как сообщить о сбое

В [GitHub Issues](https://github.com/gadpam/ChessMentor/issues) укажите SHA или ссылку на Actions, версию Android, модель телефона/эмулятора, размер шрифта и точный путь до действия. Приложите **ожидаемое и фактическое поведение**: например, «открыл №15 из архива, получил сводку №14». Для импорта достаточно минимального обезличенного PGN, для сетевой ошибки — текста сообщения и шага (ник / месяцы / партии / сохранение). Не публикуйте пароли, keystore или пользовательский JSON-бэкап.

## Где искать автоматический тест

[UI-тесты на устройстве](../app/src/androidTest/java/com/example/chessmentor/presentation/ui) названы по сценарию: `ChessComImportTest` — архив, `PgnPreviewTest` — замена PGN и копии, `LibrarySearchTest` и `LibraryAnalysisTest` — библиотека, `GraphMovePickerTest`, `ReviewNavigationTest`, `MistakeDisclosureTest` — разбор. Тест с подставным обработчиком проверяет выбор и передачу ID, а не фактическую запись в Room. За хранилище отвечает отдельный [BackupRestorePersistenceTest](../app/src/androidTest/java/com/example/chessmentor/data/local/BackupRestorePersistenceTest.kt), за настоящий поиск — [StockfishSearchTest](../app/src/androidTest/java/com/example/chessmentor/data/engine/StockfishSearchTest.kt). [JVM-тесты доменной логики](../app/src/test/java/com/example/chessmentor/domain) не требуют телефона: [`AnalysisProgressBusyStateTest`](domain/usecase/AnalysisProgressBusyStateTest.kt) — состояние движка после завершённого разбора, [`EngineFailureMidGameTest`](domain/usecase/EngineFailureMidGameTest.kt) — останов разбора при сбое Stockfish посередине партии.
